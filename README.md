# Taskito - Task Manager API (Primer Proyecto)

API REST para administrar tareas desarrollada con FastAPI, SQLAlchemy y SQLite.

## Tecnologías

- Python 3.12
- FastAPI
- SQLAlchemy
- SQLite
- Uvicorn
- Pydantic

## Instalación

```bash
git clone https://github.com/Oscar-Amacende/taskito.git

cd taskito

pip install -r requirements.txt
