# Taskito - Task Manager API (Primer Proyecto)

**API REST** para administrar tareas como una aplicación de Task Manager, como proyecto de organización de tareas y práctica de habilidades backend, desarrollada con ayuda de las siguientes tecnologías (**FastAPI**, **SQLAlchemy** y **SQLite**). Con el objetivo de practicar los métodos **GET** y **POST**

## Tecnologías

- Python 3.64
- FastAPI
- SQLAlchemy
- SQLite
- Uvicorn
- Pydantic

***
## Instalación

```bash
    git clone https://github.com/Oscar-Amacende/taskito.git

    cd taskito

    pip install -r requirements.txt
```

***
## Cómo ejecutar el proyecto

```python
    python3-64.exe .\Taskito.py
```

## Requisitos previos

```python
    pip install "fastapi[standard]"
    pip imstall sqlalchemy
```
